
# OceanFleet

OceanFleet is a console-based Java application designed to manage
cargo vessel performance records.

## Project Overview

The application stores vessel details, retrieves vessels using
their unique IDs, and identifies vessels with the highest average speed.

## Technology Stack

- Java 17
- Maven
- JUnit 5
- Java Collections Framework
- Git and GitHub

## Concepts

- Object-Oriented Programming
- Encapsulation
- Java Collections
- List traversal
- Linear Search
- Maximum value identification
- Separation of Concerns

## Project Structure

The application follows a modular Java project structure.

## Development Workflow

The project follows a use-case-driven development approach.
Each use case is implemented in a separate feature branch
and merged into the develop branch after testing.
